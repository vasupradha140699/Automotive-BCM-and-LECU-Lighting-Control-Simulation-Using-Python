# Automotive-BCM-and-LECU-Lighting-Control-Simulation-Using-Python
A Python-based automotive project that simulates Body Control Module (BCM) and Lighting Electronic Control Unit (LECU) functionality. It demonstrates headlamp, position lamp, daytime running light (DRL), and turn indicator control based on power mode, voltage, and user inputs.

## Description
This project simulates automotive lighting control using Python classes and inheritance. It models BCM and LECU behavior based on vehicle power mode, voltage, lighting switches, and turn indicator frequency inputs.

## Features
- BCM voltage and power mode monitoring
- Headlamp and position lamp activation
- DRL status monitoring
- LECU turn indicator control
- Turn indicator and hazard frequency input
- Object-oriented programming using classes, inheritance, and methods

## Technologies
- Python 
- Object-Oriented Programming (OOP)
- Classes and Inheritance
- Conditional Statements and User Input

## Objective
To practice Python programming and simulate basic automotive body electronics and lighting control test scenarios.

## Note
This is a learning simulation. It does not communicate with actual vehicle control modules or hardware.
